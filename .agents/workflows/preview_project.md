# Preview Project Workflow

This workflow describes how to start the development server and preview the MyGym project.

## Steps

1. **Start Development Server**:
   Run the following command to start the Vite development server.
   ```powershell
   npm run dev
   ```
   By default, the server will be available at `http://localhost:3000/`.

2. **Verify Preview**:
   Open your browser and navigate to `http://localhost:3000/`.
   - Ensure the login screen appears.
   - Check the console for any import resolution errors (e.g., Supabase client path).
